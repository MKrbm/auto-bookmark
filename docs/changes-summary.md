# 変更点サマリー (git diffからAIで作成)

## 0. テスト改善
- **テストケースの実用性向上**
  - 実運用に近いケースを重視
    - 404ページの処理検証
    - 複雑な見出し階層の処理確認
    - APIドキュメントの抽出テスト
  - 短いコンテンツ除外テストを削除（実用的でないため）
  - フェッチエラー/ネットワークエラーのテストを分離
    - 通信エラー処理は別モジュールで管理する方針に変更

- **テスト手法の簡略化**
  - PDFテストを`text()`ベースに変更
    - `arrayBuffer`による複雑な判定を廃止
    - HTMLドキュメント判定の簡易化を実現

## 1. スクレイピング処理の強化（scrape.ts）
  - **エンコーディング処理の改善**
  - バイナリベースの処理に移行
    - `response.text()`から`arrayBuffer`による取得に変更
    - `TextDecoder`を使用した適切なデコード処理
  - 3段階のエンコーディング検出機能
    1. Content-Typeヘッダーからの検出
    2. メタタグからの検出（バッファの先頭部分を解析）
    3. バイナリパターンからの自動検出
  - 日本語エンコーディング対応強化
    - Shift-JIS（各種異表記に対応）
      - windows-31j
      - ms_kanji
      - x-sjis
    - EUC-JP対応
    - ISO-2022-JP対応
  - エンコーディング名の正規化処理
    - 様々な表記のエンコーディング名を標準形式に変換
    - 互換性の高い実装を実現

- **コンテンツ抽出の最適化**
  - 不要要素の除外ロジックを整理
    - 広告、サイドバー、ナビゲーション等の除外
    - より柔軟なDOM構造への対応
  - 見出し抽出の改善
    - h1〜h6の階層的な取得
    - マークダウン形式での表現

  - エラーハンドリングの改善

- **パフォーマンスとデバッグのバランス**

  - 並列処理による効率性を維持
