# テストランナーの説明

## testRunnerFetched.ts について

このテストランナーは、ブックマークのスクレイピング、チャンク分割、Embedding、および検索機能をテストするためのツールです。

## テストの実行方法

このテストは2つの環境で実行できます：

### 1. ブラウザ環境でのテスト
- `src/test/testFetched.html` をブラウザで開く
- DevToolsのコンソールで詳細な出力を確認可能
  - チャンクの生成と保存の過程
  - 検索結果の類似度スコア
  - デバッグ情報

### 2. Jestによる自動テスト
```bash
npm test
```
または
```bash
yarn test
```
- 検索結果の順位を自動的に検証
- CI環境での実行に適している

## 環境設定

```bash
# プロジェクトルートに.envファイルを作成
VITE_OPENAI_API_KEY=your_api_key_here
```

## 注意点

- テストデータはコード内にハードコードされています
- chrome.storageはモック化されているため、実際の拡張機能環境は不要です
