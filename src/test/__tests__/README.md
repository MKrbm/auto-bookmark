# テスト実行方法

このディレクトリには、AI検索機能のテストを実行するための2つの方法が実装されています。

## 1. ブラウザ環境でのテスト

`testRunnerFetched.test.ts`の`runTest`関数を使用した手動テストです。

### 特徴
- ブラウザのコンソールに詳細な実行ログが出力されます
- 各ステップの処理結果を視覚的に確認できます
- Chrome拡張機能の環境により近い形でテストできます

### 実行手順
1. `test.html`をブラウザで開きます
2. ブラウザの開発者ツールのコンソールで以下の情報が確認できます：
   - チャンク生成プロセスの詳細
   - 保存されたユーザーデータ
   - 「物理学」での検索結果
   - 類似度スコアの範囲

## 2. Jestを使用した自動テスト

`describe`ブロックで実装された自動テストです。

### 特徴
- CIなどの自動化環境で実行可能
- 期待する結果を明確に検証
- OpenAIのAPIをモックして使用するため、実際のAPIキーは不要

### 実行方法
```bash
npm test src/test/__tests__/testRunnerFetched.test.ts
```

### テスト内容
- 「物理学」での検索結果が以下の順序で返されることを検証
  1. fnorioの「光と絵の具の三原色」
  2. D-WAVEのQuantum Annealing記事
  3. LangChain公式サイト

### 環境設定
- `jest.setup.ts`でOpenAIEmbeddingsのモックを設定
- Chromeストレージのモックを実装
- テスト用のベクトルデータを事前定義

## 共通の検証項目

両方のテスト方法で以下の項目が検証されます：

1. ブックマークからのチャンク生成
2. ベクトル化（Embedding生成）
3. 類似度計算
4. 検索結果のランキング

これにより、開発時の詳細な動作確認（ブラウザ環境）と、継続的な品質保証（Jest）の両方をカバーしています。
